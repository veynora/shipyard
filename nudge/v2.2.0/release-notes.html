Nudge v2.2.0 — popup shows on your working screen

Released: 2026-10-19 · Source: app/ (Rust + Tauri 2) · Platforms: macOS (Apple Silicon, Intel), Windows 10/11 (x64, ARM64)

v2.2.0 is a fix release for macOS: a due reminder now appears where you are working, including on a second monitor. Your data from v2.1.0 carries over unchanged.

Highlights

  • Second monitor. The popup used to open on the primary screen even when you were working on another one. It now opens on the screen your mouse is on, in the bottom-right corner of the window you are using.
  • Dashboard open or a full-screen app in front. While a popup is showing, Nudge becomes a menu-bar helper (no Dock icon) so macOS does not hide it or switch Spaces. The Dock icon and menu bar return when the last popup closes, if the dashboard is open or "Show in Dock" is on.
  • No more silent misses. If a popup is created but is not visible on the Space you are in, Nudge closes it (without counting it as "ignored") and shows the in-app card instead, and writes a line to ~/.nudge/nudge.log.

Known limitations

  • Not tested by eye on real hardware. The fixes come from reading the source (the tao library's cursor and monitor code) and a unit test of the screen-picking function. Not yet run with a second monitor, with a monitor placed left of or above the primary, with another app in macOS full-screen, or on another Space.
  • The popup is still a regular window, not a floating non-activating panel (as in the Python prototype). If it still does not show over a full-screen app, converting it is the next step.
  • Everything listed under "Known limitations" in v2.1.0 still applies: Windows and Intel Mac not tested, no notarization or Windows signing, API key in plaintext in .env, and so on.
