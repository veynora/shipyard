What it does

Appears where you are

The reminder shows up on the screen you're working on, without stealing focus.

One action to resolve

Mark it done, snooze it, or just type "after lunch" or "friday 5pm" to reschedule in plain language.

Characters with personality

Pick a character and a voice style (calm coach, sarcastic friend, sports commentator, movie hero). Reminders can be spoken aloud.

Easy to add things

Type a reminder in everyday words, set it to repeat, or paste a messy brain dump and let Nudge pull out the tasks and times.

Calendar import

Bring in events from Google Calendar or an ICS calendar link.

Quiet and private

Lives in the menu bar (Mac) or system tray (Windows), works offline, and keeps your reminders on your computer in ~/.nudge/ (%USERPROFILE%\.nudge on Windows).

Install

macOS

  1. Download the DMG that matches your Mac and open it.
  2. Drag Nudge into the Applications folder.
  3. The first time, right-click Nudge, choose Open, then click Open again. This build isn't notarized by Apple yet, so macOS asks once.
    If macOS still blocks it, run this in Terminal: 
    xattr -dr com.apple.quarantine /Applications/Nudge.app
  4. Look for the N in your menu bar. Open it to add your first reminder.

Windows

  1. Download the installer (x64 for most PCs, ARM64 for ARM PCs) and run it.
  2. This build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click More info, then Run anyway.
  3. Finish the installer. It installs for your user only and needs no administrator rights.
  4. Nudge needs the Microsoft Edge WebView2 Runtime for its 3D character. It's included with current Windows 10 and 11; if it's missing, the installer downloads it.
  5. Look for the N in the system tray (bottom right). Open it to add your first reminder.

Optional AI wording: open Settings from the menu bar or tray icon and add an Anthropic API key to get freshly written reminder messages. Without a key, Nudge uses its built-in wording.

Your data is stored locally in ~/.nudge/ (%USERPROFILE%\.nudge on Windows). Delete that folder to remove everything.
