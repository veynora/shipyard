Nudge v2.0.0 — Rust/Tauri rewrite

Released: 2026-10-17 · Source: app/ (Rust + Tauri 2) · Platforms: macOS (Apple Silicon, Intel), Windows 10/11 (x64, ARM64)

Nudge is rebuilt from the Python prototype as a structured Rust app with a new main window. It keeps the idea of v1.0.0: when something is due, an animated 3D character appears and tells you what to do. Reminder data stays in ~/.nudge/, in the same SQLite layout as v1.0.0.

Highlights

  • New main window. A Dashboard with a top bar (search, theme, sync, "+ New reminder", account), a side panel (navigation, character list) and views for Dashboard, New reminder, Reminders, Calendar, Brain dump, Reflection and Settings. The selected 3D character shows on the Dashboard.
  • Light, Dark or Auto. The dashboard follows your system theme by default; change it in Settings > Appearance (the popup is not themed).
  • Settings as a page. Cards for Appearance, General, Calendar and AI, each with its own Save button. Open at login and Google sign-in act immediately.
  • 8 characters. Aria, Celeste, Elara, Luna, Nova, Raven, Scarlet and Valkyrie ship in the app. The robot from v1.0.0 is not included.
  • Installers for four targets. macOS Apple Silicon and Intel DMGs, Windows x64 and ARM64 installers, each with a SHA-256 checksum.
  • Versioned builds. The version number is generated at build time instead of being edited by hand.

Carried over from v1.0.0 (ported to Rust): plain-language times and repeats, four voices (Calm coach, Sarcastic friend, Sports commentator, Movie hero), priorities, snooze handling, Google Calendar and iCal import, brain dump, weekly reflection, optional spoken reminders, and optional AI wording with your own Anthropic API key.

What's new in this version

  • Rewritten as a Rust workspace: nudge-core (parsing, store, scheduler, wording, calendar, service), nudge-platform (speech, notifications, open at login, popup placement) and a Tauri shell with tray, popup window and a 10-second engine tick.
  • Popup closed without an answer counts as "ignore for now" (30-minute snooze). High priority reminders repeat every 2 minutes up to 10 times; Normal repeats once after 10 minutes.
  • The window opens maximized and can go full screen on macOS. Tray menu: Dashboard, Add reminder, and the rest.
  • New release tooling: build/dmg (arm64 and x64 DMGs) and build/exe (Windows x64 and ARM64 installers, cross-compiled on a Mac). Output goes to build/release/.
  • Windows support: speech via PowerShell, toast notifications, open at login through the Run key, popup placed at the bottom right.

Your data

Everything is stored in ~/.nudge/ (%USERPROFILE%\.nudge on Windows): reminders.db, .env settings, nudge.log, Google sign-in. Override the folder with NUDGE_HOME.

Known limitations

  • Not tested on Windows. The installers were built on a Mac and have not been installed or run on Windows. Speech, toasts, open at login, the transparent popup and the tray icon (a macOS-style image) are unverified there.
  • Not tested on an Intel Mac, and the DMGs have not been mounted and launched on another Mac.
  • Not verified on screen: the Light/Dark themes, the settings cards, the full-width main panel at all window sizes, popup keyboard focus, and display over full-screen apps or other Spaces (may need a different macOS window type).
  • No custom characters yet. The v1.0.0 option to drop your own .glb files in ~/.nudge/characters is not available.
  • Not implemented: the dateparser fallback, migration of old ~/.nudge_* files from before v1.0.0, a bundled Google client file, and macOS Keychain storage. The Anthropic API key is still kept in plaintext in ~/.nudge/.env.
  • macOS builds are not signed with a Developer ID or notarized. Windows builds are not code-signed. There is no auto-update.
  • The macOS private API is used for transparent windows, so the app cannot go on the Mac App Store.
  • Linux and mobile are not built yet.

What's next

Calendar and AI polish, API key in the macOS Keychain, signed and notarized macOS builds, Windows testing and signing, Ubuntu, then mobile.
