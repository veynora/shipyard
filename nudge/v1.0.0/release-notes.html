Nudge v1.0.0 — first official prototype (Python)

Released: 2026-10-16 · Source: dmg-build/src/nudge.py · Platform: macOS first (Windows/Linux fallbacks)

Nudge is a reminder companion: when something is due, an animated 3D character appears in the window you are working in, tells you what to do, and lets you finish it, push it back in plain language, or shrink it to a tiny first step.

This is the first official version: a Python prototype, shipped as a macOS DMG and a Windows installer.

Highlights

  • A character that finds you. 3D popup with speech bubble and lip-synced voice, shown over the window you are using. 6 characters: robot, Nova, Raven, Scarlet, Elara and Valkyrie.
  • Say it your way. "in 20 min", "after lunch", "tomorrow 9am", "too tired", "every weekday 9am", "every 2 hours". No snooze buttons to learn.
  • Four personalities. Calm coach, Sarcastic friend, Sports commentator, Movie hero. With an Anthropic key the wording is fresh each time; without one, built-in templates are used.
  • Stays on top of it. Priorities (Low/Normal/High), repeating reminders with active hours, snooze counts and excuses remembered, "tiny first step" splitting after repeated snoozes.
  • Calendar aware. Google Calendar sign-in or any iCal link; meeting reminders before they start with one-click join links; optionally add your Nudge reminders to Google Calendar.
  • Menu bar companion. Starts quietly in the menu bar, shows what is next, pause for an hour, open at login.
  • Extras. Brain dump (turn a ramble into reminders), weekly reflection, spoken reminders ("speak …"), macOS notification banners.

What's new in this version

  • First packaged macOS DMG and Windows installer (Windows adds a tray menu and open-at-login).
  • Version label reset to 1.0.0.
  • Not included yet: Aria, Celeste, Luna (experimental v18/v19).

Requirements (running from source)

  • macOS (primary), Python 3.
  • For the 3D popup: pywebview plus the PyObjC frameworks (Cocoa, Quartz, WebKit). Without them a simple popup is used.
  • Optional: dateparser, icalendar, recurring-ical-events, certifi, google-api-python-client, google-auth-oauthlib.

Run

python3 nudge.py   # from dmg-build/src/

Your data

Everything is stored in ~/.nudge/ (reminders database, .env settings, logs, Google sign-in, your own characters). Data and settings from older prototypes (~/.nudge_reminders.db, settings.json) are migrated automatically on first launch.

Known limitations

  • No auto-update. Signing/notarization requires your own certificates, otherwise users see the OS security prompt.
  • Running nudge.py directly needs vendor/ (three.js) and the .glb files beside it (or in ~/.nudge/characters/); the installers already include them. buddy is mentioned in settings help but has no model.
  • No automated tests.
  • The Anthropic API key is saved in plaintext in ~/.nudge/.env (owner-only permissions).

What's next

Signed and notarized builds by default, auto-update, Windows then Linux, open character-pack format (see development/nudge/PRD.md).
