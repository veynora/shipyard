Nudge v2.1.0 — templates, Skip, multiple calendars, macOS menu bar

Released: 2026-10-18 · Source: app/ (Rust + Tauri 2) · Platforms: macOS (Apple Silicon, Intel), Windows 10/11 (x64, ARM64)

v2.1.0 makes reminders quicker to create and easier to manage: start from a template, edit any reminder, skip one you don't want, and pull in several calendars. On macOS the app now has a proper menu bar. Your data from v2.0.0 carries over unchanged.

Highlights

  • Reminder templates. The New reminder form has a "Start from a template" row: Drink water, Stretch break, Stand up, Take medicine, Wind down, Review my day. A click fills the task, repeat, priority and say-it-out-loud; you pick the time. Built-in only (no saved templates yet).
  • Skip. A "not this time" answer that does not mark the reminder done and does not snooze it. A repeating reminder moves to its next time; a one-off is finished, and a calendar sync will not bring it back. Skip is in the popup (next to "Ignore for now"), on the due card, and in the Reminders table and dashboard list.
  • Dashboard tiles. New "Done (7 days)" and "Skipped (7 days)" tiles beside Due today, Overdue, Upcoming and Snoozed 3+. Skips never count as done or in the weekly reflection.
  • Edit any reminder. Click a reminder (or Edit) to change its task, time, repeat, priority or speak setting, including calendar reminders. New and Edit share one centered popup with a date and time picker.
  • Multiple calendars. Integrations is now a list: any number of iCal links plus Google, each with its own name, remind-before times (for example 1 day, 1 hour, 10 minutes, at the start), all-day time, speak, look-ahead and add-to-calendar. Spoken reminders say how long is left.
  • macOS menu bar. While the main window is open Nudge is a regular app with a Dock icon and its own menus (Nudge, Edit, View, Window, Help), so ⌘, opens Settings and ⌘C / ⌘V work in text fields. The green button zooms the window and keeps the menu bar; full screen is under View. Closing the window returns Nudge to the menu bar only (unless "Show in Dock" is on).
  • Cancel and Delete work again. Cancel, ✕, Esc and Delete did nothing when a form had changes, because the webview has no native confirm box. They now use an in-app dialog (Discard / Keep editing, Delete / Cancel).

What else changed

  • Reminders page: one filter row with a multi-select Source dropdown, a calendar status link, "+ New reminder" and "Brain dump" (now a dialog). The Calendar and Brain dump pages are gone; calendar setup moved to Integrations.
  • Top bar: labelled "⟳ Sync all" button with progress ("Syncing…", "Synced ✓", "Sync failed"), and a "Quick reminder" button. The bar clears the title bar and notch area in every window state.
  • Menu bar menu reorganised, with a Pause reminders submenu (30 minutes, 1 hour, 2 hours, Until tomorrow).
  • Settings defaults (character, voice, priority) are dropdowns.
  • Fixed: the Windows exe, shortcuts and installer showed a generic or blurry icon; they now carry the full Nudge icon (16 to 256 px), the same artwork as the Mac icon. The Mac DMG volume shows the Nudge icon.
  • Fixed: reopening Settings lost the Google Calendar box; the tray "Add reminder…" fallback now opens New reminder; screen readers now get button labels.
  • Removed: the per-reminder Preview button (it fired the real reminder early).

Your data

Same as v2.0.0: ~/.nudge/ (%USERPROFILE%\.nudge on Windows) with reminders.db, .env, nudge.log and Google sign-in; override with NUDGE_HOME. No schema change: skipped reminders are stored as rows with status skipped in the existing table, so v2.0.0 and the Python prototype ignore them. Existing single-link calendar settings migrate to the new calendar list automatically.

Known limitations

  • Not tested on Windows. The installers are cross-compiled on a Mac and were not installed or run on Windows.
  • Not tested on an Intel Mac, and the DMGs were not mounted and launched on another Mac.
  • Icons not checked on a real Windows machine (clean install: setup, shortcuts, taskbar, Apps list) or in Finder/Dock/Launchpad. The build scripts verify the icon files and resources only.
  • Not checked by eye on macOS: the new menu bar, zoom and full-screen behaviour, the top bar in every window state, the extra Skip button in the popup, and the six dashboard tiles in light and dark themes at narrow widths. The code and automated tests (Rust, and the UI smoke test with a mocked backend) pass.
  • The top-bar clipping in full screen was fixed from a likely cause (the bar sat under the revealed menu bar or notch area); it was not reproduced.
  • Templates are built-in only; there is no way to save your own. The popup's New reminder wizard has no template row.
  • No custom characters, no auto-update, no Developer ID signing or notarization, no Windows code signing, and the Anthropic API key is still stored in plaintext in ~/.nudge/.env. Linux and mobile are not built.
