Nudge v2.3.0 — popups side by side, lock-screen fix, Robot removed

Released: 2026-11-18 · Source: app/ (Rust + Tauri 2) · Platforms: macOS (Apple Silicon, Intel), Windows 10/11 (x64, ARM64)

v2.3.0 fixes three popup and character problems. Your data from v2.2.0 carries over; reminders and a default character set to "Robot" become Nova on first launch.

Highlights

  • Popups no longer cover each other. Reminders that fire together sit side by side (newest on the left). If the screen is too narrow for another one, extra reminders wait in a queue, the rightmost popup shows "+N waiting", and a closing popup lets the next one in.
  • Locked Mac or sleeping display (macOS). A reminder that fell due while the screen was off used to show its speech bubble with no character. Reminders now wait while the screen is off and appear once, about half a second after it is back. Allow a short delay: the screen state is checked every 10 seconds.
  • Dashboard hero after picking a character. Choosing another character after "Robot" no longer leaves the 🤖 emoji in the hero card.
  • Robot removed. The built-in Robot character is gone; Nova is the default and the fallback. If a character model cannot load, you see an empty placeholder instead of an emoji; the popup dialog still appears.

Your data

~/.nudge/ (%USERPROFILE%\.nudge on Windows). No schema change, but a one-way data migration runs on first launch: existing reminders and a saved default character of "robot" become Nova. Characters without their own voices now use Nova's voices.

Known limitations

  • Not tested by eye on real hardware. The popup layout, the lock-screen behaviour and the placeholder were checked with unit tests and the UI smoke test only, not with several popups on screen, a real locked Mac or a second monitor.
  • No click-to-focus on the notification sent while the screen is off.
  • Everything listed under "Known limitations" in v2.2.0 and v2.1.0 still applies: Windows and Intel Mac not tested, no notarization or Windows signing, API key in plaintext in .env.
  • A dependency audit found updates for two TLS crates and the bundled SQLite that are not in this release (see SECURITY_AUDIT.md in the project's releases/v2.2.0/).
